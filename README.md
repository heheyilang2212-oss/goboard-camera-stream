# goboard-camera-stream
カメラで碁盤を認識し、盤面をリアルタイム中継するWebアプリ

## 操作方法

- スマホ単独: 「配信する」でカメラを許可し、「スマホで操作」のまま設定します。
- PC併用: スマホの「PC操作も許可」を選びます。PCに部屋IDを入力して「PCから操作する」を開き、スマホに表示された12文字の操作コードで接続します。
- 観戦: 従来どおり部屋IDまたは観戦URLで参加できます。操作コードは観戦者に共有しないでください。

PCでは静止画による向き・四隅の設定、カメラ選択、認識設定、認識の一時停止・再開、手番・パス・棋譜操作、石の手動修正、PNG/SGF保存ができます。スマホの操作も残ります。「スマホで操作」に戻すとPCの権限を取り消します。

動画はPCへ常時送信せず、設定時に静止画を取得します。スマホはスリープさせず、このページを前面で開いておいてください。カメラの許可やブラウザ・OSの設定はスマホで必要です。認識の一時停止中も観戦接続と最後の盤面表示は維持します。

## 検証

`node tests/regression.cjs`（追加依存なし）。疑似DOM・接続と合成画像による回帰テストです。実機のカメラ、照明、ネットワーク環境での確認は別途必要です。
